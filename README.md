# Store App

A product catalog with image search, recommendations, comments, and a cart.

The Flask backend is in `backend/`, the React/Next.js frontend is in `frontend/`, and infrastructure definitions are in `terraform/`.

For frontend development, install the dependencies in `frontend/` and run `npm run dev`. The backend requires PostgreSQL and the service endpoints supplied through its command-line arguments. Cloud deployment requires operator-provided AWS credentials and incurs charges.
